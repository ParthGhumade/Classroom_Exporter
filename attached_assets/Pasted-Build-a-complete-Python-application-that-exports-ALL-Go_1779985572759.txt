Build a complete Python application that exports ALL Google Classroom files from ONE specific classroom/course into a chosen Google Drive folder.

Requirements:

GOAL:
- Read all assignments, materials, announcements, and coursework from a selected Google Classroom course
- Find every attached Google Drive file
- Copy those files into a target Google Drive folder
- Preserve metadata and avoid duplicates

TECH STACK:
- Python 3
- google-api-python-client
- google-auth-oauthlib
- google-auth-httplib2

AUTH:
- Use OAuth 2.0 Desktop App flow
- Store token locally in token.json
- Automatically refresh expired tokens
- Provide setup instructions for Google Cloud Console

GOOGLE APIS:
- Google Classroom API
- Google Drive API

FEATURES:
1. List all Google Classroom courses
2. Let user choose one course
3. Let user input a target Google Drive folder ID
4. Fetch:
   - coursework
   - course materials
   - announcements
5. Extract all attached Google Drive file IDs
6. Copy files to target Drive folder using Drive API
7. Skip duplicate copies using:
   - original file ID tracking
   - or filename matching
8. Create a metadata.json log file containing:
   - original file ID
   - copied file ID
   - source assignment/material name
   - timestamp
9. Handle pagination correctly everywhere
10. Handle API errors and retries gracefully
11. Ignore non-Drive attachments such as:
   - links
   - YouTube videos
   - forms
12. Print detailed progress logs
13. Use clean modular architecture

IMPORTANT EDGE CASES:
- Some materials may not contain driveFile
- Some files may be shortcuts
- Some files may already exist in target folder
- Some files may not be copyable
- Handle permission errors safely
- Avoid crashing on malformed data

OUTPUT:
- Generate complete production-quality code
- Include requirements.txt
- Include setup instructions
- Include comments explaining important parts
- Keep everything in a SINGLE Python file for now

The app should work immediately after:
1. Enabling APIs
2. Downloading OAuth credentials.json
3. Running:
   pip install -r requirements.txt
4. Running the script

Use best practices and robust error handling.
